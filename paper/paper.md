# Summary
Bead-Spring Analytics is a Python package for analysing coarse-grained molecular dynamics simulation trajectories. The library builds on MDAnalysis [@gowers2016mdanalysis], NumPy [@harris2020array], (and others) to compute structural and dynamical properties of bead-spring polymer models [@kremer1990dynamics].

# Statement of need
Simulation of polymer systems produces extensive trajectory data that require specialised analysis. Existing packages either focus on specific observables or rely on object-oriented frameworks. Bead-Spring Analytics provides a lightweight, functional approach that allows researchers to compose reusable functions for common analyses.
